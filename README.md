# Roasted Cherry Tomato Chicken Salad

A mobile-friendly static recipe page for Roasted Cherry Tomato Chicken Salad with Creamy Dijon Yogurt Dressing.

## GitHub Pages

This folder is ready to upload to GitHub Pages.

1. Create a new repository on GitHub.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**.
4. Choose your main branch and the root folder.
5. Save and wait for GitHub Pages to publish the site.
